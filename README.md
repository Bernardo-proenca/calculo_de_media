# Calculadora de Média

*Programa que recebe 2 notas, calcula a média e diz se você está aprovado ou reprovado*

**A linguagem utilizada foi: Python 3.13**

***

# Como executar localmente

1. Instale o Python 3.13.
2. Baixe ou clone o projeto.
3. Abra o terminal n apasta do projeto.
4. Execute:
python calculadora.py
5. A calculadora será iniciada no terminal e estará pronta para uso.

## Exemplo de uso

- Digite a primeira nota: 8
- Digite a segunda nota: 6
- A média final é: 7.00
- Status: APROVADO!
